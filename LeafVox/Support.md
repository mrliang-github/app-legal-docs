## English

### About LeafVox

LeafVox is a local-first iPhone reader that lets you import supported EPUB and TXT files, read them with adjustable themes and text size, and listen with iOS system voices.

### Requirements

- iPhone
- iOS 17.0 or later
- A DRM-free, reflowable EPUB file or a supported text file

### Importing a Book

1. Open LeafVox and tap **Import File**.
2. Select a file in Apple's document picker.
3. Review the local inspection result.
4. Confirm the import.

LeafVox currently imports:

- DRM-free, reflowable EPUB
- TXT encoded as UTF-8, UTF-16, or GB18030

LeafVox can identify some PDF, MOBI/AZW3, Word, and protected Kindle files, but it does not import those formats in the current version. Fixed-layout, image-only, or DRM-protected EPUB files are also unsupported.

### Reading and Listening

- Open a book from the library to continue reading.
- Use the reader controls to choose a system voice, speech rate, theme, and text size.
- When read-aloud playback is active, supported lock-screen and system media controls are available.
- Voice availability depends on the voices installed or offered by iOS for the book's language.

### Deleting a Book

1. Open the book.
2. Tap the **More** button in the top-right corner.
3. Choose **Delete This Book** and confirm.

This removes LeafVox's local copy and related reading data. It does not modify the original file outside the app.

### Troubleshooting

#### A file is shown as unknown or blocked

LeafVox checks the file's actual structure instead of trusting only its extension. Choose another copy if the file is incomplete, still downloading from a cloud provider, protected by DRM, or not one of the supported formats.

#### An iCloud Drive file cannot be read

In Files, make sure the file has finished downloading to the device, then select it again in LeafVox. Keep LeafVox open while a large cloud file is being prepared.

#### A book has no voice in its language

Open iPhone **Settings > Accessibility > Spoken Content > Voices** and check whether an appropriate iOS voice is available. Then return to LeafVox and select the voice in Reader Controls or Settings.

#### Playback stops after locking the phone

Start playback inside the reader before locking the phone. If it still stops, reopen LeafVox, verify that the book is available locally, and restart playback. Include your iPhone model, iOS version, and LeafVox version when contacting support.

#### The app cannot open a book

Try importing a known-good, DRM-free reflowable EPUB or plain-text file. LeafVox intentionally blocks active content, remote book resources, unsafe archive paths, and protected publications.

### Privacy

Book files, book text, reading positions, and app settings are processed locally. See the complete [LeafVox Privacy Policy](PrivacyPolicy.html).

## 中文

### 关于 LeafVox

LeafVox 是一款本地优先的 iPhone 阅读器，可以导入受支持的 EPUB 与 TXT 文件，调整阅读主题和字号，并使用 iOS 系统声音朗读。

### 系统要求

- iPhone
- iOS 17.0 或更高版本
- 无 DRM、可重排版的 EPUB 文件，或受支持的文本文件

### 导入书籍

1. 打开 LeafVox，点击**导入文件**。
2. 在 Apple 系统文件选择器中选择文件。
3. 查看本地检查结果。
4. 确认导入。

LeafVox 当前可以导入：

- 无 DRM、可重排版的 EPUB
- UTF-8、UTF-16 或 GB18030 编码的 TXT

LeafVox 可以识别部分 PDF、MOBI/AZW3、Word 和受保护的 Kindle 文件，但当前版本不会导入这些格式。固定版式、纯图片或受 DRM 保护的 EPUB 也不受支持。

### 阅读与朗读

- 从书库打开书籍即可继续阅读。
- 使用阅读控制调整系统声音、朗读速度、阅读主题和字号。
- 开始朗读后，可以使用受支持的锁屏和系统媒体控制。
- 可用声音取决于 iOS 是否为书籍语言安装或提供了相应声音。

### 删除书籍

1. 打开需要删除的书籍。
2. 点击右上角的**更多**按钮。
3. 选择**删除这本书**并确认。

该操作会删除 LeafVox 的本地副本及相关阅读数据，不会修改 App 之外的原始文件。

### 常见问题

#### 文件显示为未知或已阻止

LeafVox 会检查文件的真实结构，而不只相信扩展名。如果文件不完整、仍在等待云端下载、受 DRM 保护或不是受支持格式，请换一个文件副本后重试。

#### 无法读取 iCloud Drive 文件

请先在“文件”App 中确认该文件已经下载到设备，再回到 LeafVox 重新选择。准备较大的云端文件时，请保持 LeafVox 在前台运行。

#### 找不到书籍语言对应的声音

请打开 iPhone **设置 > 辅助功能 > 朗读内容 > 声音**，确认 iOS 是否提供了合适的声音，然后回到 LeafVox 的阅读控制或设置中重新选择。

#### 锁屏后朗读停止

请先在阅读器中开始朗读，再锁定手机。如果仍然停止，请重新打开 LeafVox，确认书籍已保存在本机并重新开始朗读。联系技术支持时请提供 iPhone 型号、iOS 版本和 LeafVox 版本。

#### App 无法打开书籍

请尝试导入一个确认有效、无 DRM、可重排版的 EPUB 或纯文本文件。LeafVox 会主动阻止活动内容、远程书籍资源、不安全的压缩路径以及受保护的出版物。
